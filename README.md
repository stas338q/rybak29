# 🎣 Рыбак29 — помощник рыбака Архангельской области

Сайт: **https://stas338q.github.io/rybak29/**

Чат-бот с нейросетью, который отвечает на вопросы о рыбалке в Архангельской области:
места (Северная Двина, озёра, Белое море), мормышки и снасти, навага, корюшка, налим, щука, окунь,
нерестовые запреты и нормы вылова, безопасность на льду, календарь рыбака.

Нейросеть работает прямо в браузере, без сервера.
